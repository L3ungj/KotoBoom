# KotoBoom
An entry to the 2026 Magical Mirai Programming Contest

### Overview
This project is a 3D lyrics visualiser that shows words as fireworks in a night sky. Users can wander around the scene by controlling the character Hastune Miku.

### Usage
1. Go to the [GitHub Pages site](https://l3ungj.github.io/MikuContest2026/) 
2. Select a song by pressing the music icon in the bottom right corner
3. Use WASD controls or touch controls to move around the scene
4. Press the Camera / Eye icon in the bottom left corner to switch between first-person and orbit camera modes
5. When the cubes appear, press on the cubes to push them around.
6. Enjoy the fireworks and the wonderful music!

### Key Features
- Animated 3D Miku model that can be controlled by the player
- First-person mode and orbit camera mode
- Firework effects for each word in the lyrics, colored by part-of-speech
- Beat-synced effects, e.g. Miku head shakes, floor pulses
- Immersive chorus effects, e.g. floating cubes, stars approaching, etc.
- Custom physics for Miku hair movement
- Mobile friendly, with touch controls for movement and camera

### Technologies Used
- React + TypeScript
- Tailwind CSS
- Three.js + React Three Fiber
- TextAlive API
- Rapier physics engine
- gh-pages for deployment to GitHub Pages
